任务说明

  • 源：一个网盘远程 + 目录（也可填直链 url，交给 aria2 多线程断点下载）。
  • 目标：一个或多个网盘远程，默认取与源同名目录。
  • 模式：全量（目标镜像源，删除多余）/ 增量（仅新增更新，不删除）。
  • 双向：开启后源↔目标互为镜像（需单一目标）。
  • 定时：手动一次性 / 周期 interval / cron 表达式。
  • 所有传输均断点续传（rclone .partial / aria2 .aria2，缓存卷持久化）。

🌐 一键接入 OpenList / AList (WebDAV)

最快的方式：填你已有 OpenList（或 AList）的 DAV 地址 + 账号密码，即可把 OpenList 挂载的所有网盘纳入管理（类似 taoSync 接入 OpenList 引擎）。默认 DAV 路径为 /dav（如 http://openlist:5244/dav）。

网盘账号 / Cookie 配置（高级，手动编辑 rclone.conf）

此处即 rclone.conf。支持所有 rclone 后端（百度/阿里/Google Drive/OneDrive/S3/WebDAV/AList 等）。Cookie 类网盘填入对应驱动字段即可。也可在任意机器 rclone config 生成后整段粘贴这里。

-

保存后，请在「任务」里选择远程 + 浏览目录。
